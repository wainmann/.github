# Security policy

This policy covers every repository in the [Wainmann organization](https://github.com/wainmann). If a project has its own `SECURITY.md`, read that one too.

## Supported versions

Security fixes land on the latest release of each project. Please check the newest version before reporting, in case the issue is already fixed.

## Reporting a vulnerability

Please report it privately. Open the repository, go to the **Security** tab and choose **Report a vulnerability**. If that option isn't available, email [contact@wainmann.com](mailto:contact@wainmann.com) with "Security" in the subject line.

Please don't open a public issue, discussion or pull request for a vulnerability, and keep the details private until a fix is released.

A good report says what an attacker can do, what access they need first, the steps to reproduce, and the project version and OS you used.

## Out of scope

- Bugs in third-party AI agents or CLIs that these tools launch or connect to. Please report those to their maintainers.
- Anything that requires an attacker to already have write access to your config files or your shell.
