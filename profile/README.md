Making AI agents do the work, for one person or a whole company.

Wainmann builds tools for people and teams who work with AI agents every day. We want agents to be reliable enough to hand real work to, and easy to keep an eye on while they do it.

## Projects

### agent-manager

Open source. agent-manager runs the coding agents you already use, such as Claude Code, Codex, OpenCode and Gemini CLI, side by side in one terminal UI. You can follow what each agent is doing, send prompts, work in separate worktrees and review diffs without leaving the keyboard. It ships as a single binary with no server and no account.

[Repository](https://github.com/wainmann/agent-manager) · [Documentation](https://agent-manager.dev) · [Discord](https://discord.gg/ecS88An7pF)

### Software Factory Builder

Software Factory Builder is a canvas editor where teams design and run software factories as flows. It connects to the agents a team already uses and keeps shared context across dev, docs, design and DevOps work. It is not open source at the moment.

[softwarefactorybuilder.com](https://softwarefactorybuilder.com)
